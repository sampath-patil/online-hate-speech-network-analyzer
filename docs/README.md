Put your app screenshots in this folder.

The README expects these four filenames (rename your screenshots to match and
the images will appear automatically):

    screenshot-overview.png    the Overview tab
    screenshot-network.png     the Network & Spreaders tab, after building the graph
    screenshot-train.png       the Train & Evaluate tab, showing metrics
    screenshot-classify.png    the Classify tab, showing a prediction

On Windows, press Win+Shift+S to capture a region of the screen, then paste it
into Paint and save as PNG.
